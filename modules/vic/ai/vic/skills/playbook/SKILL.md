# PLAYBOOK LAW (vic, global) CVMN — expensive insight runs ONCE, then becomes cheap procedure.

## WHY (the haiku→fable lever)
Smart-model value = decisions. Playbook PRE-MAKES them: which files, oracle shape, traps, order. Remainder = mechanical ⟹ cheap tier executes near-expert. Receipts: frozen procedure ⟹ 8× first-run-green; spec-quality bought tier-downgrades repeatedly.

## USE (supervisor, b4 dispatch)
1. Check <proj>/vic/playbooks/. Match → dispatch w/ "follow <playbook>; deviations = SPEC GAP back". Playbook + thin params = whole spec.
2. No match + recurs ≥2 more times → solve once at proper tier, then FREEZE via vic-scribe.
3. Playbook'd task drops ONE tier (opus→sonnet; sonnet→haiku IF oracle mechanically checkable).

## FREEZE TEMPLATE (vic-scribe writes from session evidence, ≤60 lines)
`# PB: <class> (tier: X w/ this PB)` + WHEN + STEPS (exact, each w/ file/cmd/check; locate via codegraph, NEVER memorized line numbers — lines rot) + ORACLE (+ negative-control template) + TRAPS (every mistake made first time + kill receipts) + `DONE = <pasteable evidence list>`.

## MAINTAIN
Playbook caused a wrong step → fix SAME session (load-bearing infra, not docs). Superseded → DEAD note inside, keep (anti-re-thrash). Index in project INDEX.
