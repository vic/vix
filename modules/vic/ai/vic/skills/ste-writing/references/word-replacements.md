# ASD-STE100 Curated Word Replacements

| Avoid (Slop / Complex / Ambiguous) | Use (Plain STE) |
|---|---|
| `utilize`, `leverage`, `employ` | `use` |
| `commence`, `initiate`, `begin` | `start` |
| `terminate`, `cease`, `finalize` | `stop`, `end`, `finish` |
| `facilitate`, `assist`, `enable` | `help`, `let`, `allow` |
| `ensure` (strict STE) | `make sure` |
| `prior to` | `before` |
| `subsequent to` | `after` |
| `regarding`, `concerning`, `pertaining to` | `about` |
| `obtain`, `acquire` | `get` |
| `demonstrate`, `illustrate` | `show` |
| `additionally`, `furthermore`, `moreover` | `also` |
| `perform an analysis of` | `analyze` |
| `make a modification to` | `change` |
| `spin up`, `kick off`, `wind down` | `start`, `stop` |
| `in order to` | `to` |
| `at this point in time` | `now` |
| `seamless`, `robust`, `powerful`, `cutting-edge`, `effortless`, `world-class`, `next-generation`, `revolutionary`, `comprehensive`, `delve` | *(delete — state the concrete behavior or number instead)* |
