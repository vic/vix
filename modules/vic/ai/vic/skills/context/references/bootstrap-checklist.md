# Fresh 4-Read Bootstrap & Doc-Budget Checklist

## 1. Cold-Start 4-Read Manifest (`<= 4K` tokens total)
- [ ] **Read 1:** `<proj>/vic/HANDOFF.md` (resume state, `NEXT-CMD`, active workspaces)
- [ ] **Read 2:** Project workflow / law file (commands, roles, gates)
- [ ] **Read 3:** ONLY the active task brief + cited spec section/ruling (never sweep all specs or all briefs)
- [ ] **Read 4:** Matching `<proj>/vic/playbooks/<slug>.md` (if recurring task class)

## 2. Hard Byte-Budget Gate (for doc/summary/compression dispatches)
Always include in the brief:
- `HARD BUDGET: output <= <N> bytes (or <= <M> lines). Verify with wc -c / wc -l; over budget = GATE FAIL.`
- `ANCHOR PRESERVATION: preserve every [LNNN] / Rnn / file:line citation verbatim.`
